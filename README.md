## Component List
- Navigation: sticky header, dropdown menus, mobile slide panel, CTA button
- Buttons: primary, ghost, inline text link
- Cards: service cards, portfolio cards, metric cards, testimonials, value cards
- Filters: chips, dropdown-friendly filters
- Forms: newsletter, contact form, select inputs, textarea
- Tables: support package comparison
- Accordions: FAQ details/summary
- Media blocks: gallery, featured post, map placeholder
- Footer: multi-column nav, contact info, social links

## Responsive Behavior Notes
- **Desktop**: 12-column grid, sticky sidebar for resources, full navigation with dropdowns.
- **Tablet**: stacked hero content, collapsible spacing, cards wrap to 2 columns.
- **Mobile**: hamburger menu reveals slide panel, CTA buttons stack, tables become horizontally scrollable, sidebar moves inline.

## Style Guide (Quick Reference)
- **Color Palette**
  - Primary: #0B1220
  - Accent: #3B82F6
  - Neutrals: #F5F7FB (section), #FFFFFF (base), #0F172A (text)
- **Typography**
  - Headlines: Bold geometric sans (recommended: `Inter`, `Manrope`, or `Sora`)
  - Body: Clean sans (recommended: `Inter`)
  - H1: 2.6–3.6rem
  - H2: 2–2.6rem
  - H3: 1.2–1.5rem
- **Spacing**
  - Section padding: 96px vertical, 24px horizontal
  - Card padding: 24px
  - Layout max-width: 1200px
- **Motion**
  - Hover: button lift, card lift, accent border glow
  - Scroll reveal: subtle fade + translate
